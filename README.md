# TCC: Estudo Comparativo de CNNs para Classificação de Imagens de Células Sanguíneas

## 📝 Descrição
Este trabalho apresenta um estudo comparativo de três arquiteturas de Redes Neurais Convolucionais (CNNs) aplicadas à classificação de imagens de células sanguíneas quanto à presença de contaminação.

Foram comparados:
- *CNN Própria* — arquitetura desenvolvida do zero
- *VGG16* — modelo pré-treinado
- *ResNet50* — modelo pré-treinado
